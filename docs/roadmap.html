Where we are (2026-08-22)

Waves 1 and 2 are complete (foundations through the drawn file dialog, sealed by the contract-assault suite). Wave 3 is nearly closed: the indicator septet, the disclosure batch (accordion, stepper, timeline, drawers with tabbed peek-and-pin gutters, popovers), the 7GUIs benchmark and the organs it forced (canvas, sheet, validity tint, the application clock), the data-grid crown, the culture batch (locale, calendar, date and time pickers), the tree, and the colour picker. 58 classes, 73 contract assaults, a documentation page per control.

The method carries forward unchanged: every control ships in one commit with demo wiring, assault tests where the model allows, and its own documentation page; specs/S04-ROADMAP.md is the per-control docket, harvested from the same sources as the pages so the two cannot drift. This page is the narrative view; S04 is the checklist; S02 is the charter.

Cross-cutting toolkit work (between the waves)

  • Undo/redo engine for SW_TEXT_BOX - the most-missed feature; command-pattern edits.
  • Focus traversal (Tab order) - unlocks default buttons, keyboard activation everywhere, list/grid keyboard selection polish.
  • Dirty-rect rendering + batched text runs - erases the residual resize/scroll lag; per-widget draw-time histograms ride it (inspector performance pane).
  • Drawn-glyph set - icon buttons, toolbar icons, segment icons, tree node icons, all R7-pure.
  • Cursor API - I-beam over text, resize arrows over splitters and grid dividers.
  • Overlay engine growth - top/bottom drawer gutters (the add_drawer_tab signature already accepts all four edges), slide/ease animation on the heartbeat, peek-close grace delay, popover auto-close-on-pick.
  • Window auto-scroll policy - the window offers scrollbars itself when root content overflows (today: compose a scroll-area body, as the demo shell does).
  • Locale growth - number formatting consuming the carried decimal mark; collation for grid sorting; Windows ICU bridge when CLDR depth is demanded.
  • Timezone tools - SW_WORLD_CLOCK (per-zone ticking times) and SW_TIMEZONE_PICKER (band map, graduating with Wave 4's maps).
  • Dependency audit - sweep ECFs and sources for ISE/Gobo touchpoints; map each to a simple_* library or flag the backfill hole (simple_datetime was the live win; the file dialog's base PATH/DIRECTORY is the first candidate).
  • Theme text scale - Larry's grow/shrink-font control applied theme-wide.
