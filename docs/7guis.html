What this is

7GUIs is a GUI-programming Rosetta stone: seven tasks, each isolating one essential difficulty - basic wiring, bidirectional dataflow, constraints, time, domain/presentation separation, custom drawing with undo, and change propagation. Implementing all seven certifies a toolkit can state every fundamental GUI problem. The app lives in demo7guis/; build it with target sw_7guis.

This implementation has a property no other entry in the benchmark's table has: Design by Contract in the seams. The timer cannot hold an out-of-range fraction, the stepper clamps by postcondition, and the cells engine's first cycle bug was caught by an assault test refusing to pass - the benchmark implemented under the same gates as the toolkit itself.

Proofs

Every behaviour was driven synthetically and photographed via the frame echo: 32100 C → 57812 F (the formula exact), the red invalid date with Book disabled, the timer resuming when its duration grew past elapsed, the filter narrowing and emptying honestly, two circles → undo → redo, and A0 edited to 50 propagating B0=100 and A2=55.5 in one commit. The domain engines carry eight assault tests (cycle detection earned its fix by failing first).
