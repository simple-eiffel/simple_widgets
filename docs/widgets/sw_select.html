Description

SW_SELECT is the classic non-editable dropdown. It renders the selected option (or a muted 'choose…' placeholder), and any click opens a drawn menu of all options via the pending-menu handshake. select_index moves the selection and fires on_change.

Choose SW_SELECT when the value set is closed; choose SW_COMBO when users may type their own.

Source: src/sw_select.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

A kind picker with immediate feedback

create kind_select.make
kind_select.add_option (class="string">"Info")
kind_select.add_option (class="string">"Success")
kind_select.add_option (class="string">"Warning")
kind_select.add_option (class="string">"Danger")
kind_select.set_on_change (agent on_kind_changed)
kind_select.set_tooltip (class="string">"Picking one previews it")

on_kind_changed
    do
        -- the immediate-feedback rule: show, don't wait
        window.toast (class="string">"Previewing: " + kind_select.selected_text, kind_select.selected_index)
    end

Known limits

  • Single selection only; no multi-select variant yet.
  • The menu shows all options at once - no scroll for very long lists.
  • Per-option enabling and group separators SHIPPED 2026-08-23: set_option_enabled and add_separator_after.

Bugs & gotchas

  • selected_index = 0 means nothing chosen yet and selected_text is empty - guard first use.
  • Options are copied in as STRING_32; mutating the string you passed changes nothing.

Extension plans & possibilities

  • Option groups with separators; per-option enabled flags.
  • A multi-select variant rendering chips of the chosen set.
  • Type-to-jump (first-letter navigation) while the menu is open.
