SW_WAVEFORM

The amplitude envelope of a sound, a playhead, and markers down the time axis - buffer-agnostic by design.

Description

One vertical bar per pixel column, drawn from a summary of lows and highs the widget reads once through a sampler agent: count, sample rate, and a function answering frame i (0-based, so simple_audio's agent buffer.sample_at (?, 0) passes verbatim). A nine-minute recording is twelve million samples; the widget keeps 4,096 columns of peaks and re-buckets them to whatever width it is painted at. The played part draws in the accent, the rest muted, the playhead in the caret colour, markers as warning ticks wearing a mono label. A silence is a flat centre line - which is exactly the gap a pacing gate measures.

A click or drag seeks and fires on_seek with the second; the host that owns the player reports real progress back through set_position. position_at, x_of and column_peaks are public and assaulted headless.

Source: src/sw_waveform.e · since 0.8.0 (2026-09-05), built for simple_narrate's Studio.

Wired to simple_audio

create wave.make (72.0)
wave.set_samples (buf.frame_count, buf.sample_rate, agent buf.sample_at (?, 0))
wave.add_marker (1.42, "sentence")
wave.set_on_seek (agent player_seek)
-- heartbeat: wave.set_position (player.position)

Known limits

  • Mono envelope: a stereo buffer is summarised through whichever channel the sampler answers.
  • No selection range, no zoom; the whole sound fills the width, v1.

Bugs & gotchas

  • Samples outside [-1, 1] are clamped, not refused: a mis-scaled float buffer draws full-scale rather than painting outside the box.
  • The summary is read at set_samples and never again; a buffer the host mutates afterwards is not reflected until it is set again.

Extension plans & possibilities

  • A selection range (in and out points) for trimming; a zoomed window over a long recording; per-channel lanes.
