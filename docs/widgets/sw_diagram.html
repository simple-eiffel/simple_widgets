Description

The force layout the dev-mode mesh proved - all-pairs repulsion, edge springs, centre gravity, one relax per heartbeat, the EiffelStudio Diagram Tool's family - as a PUBLIC widget carrying YOUR nodes: add_node (label) returns an id, connect refuses unknown ids and self-loops by contract, and every node ring-seeds deterministically on the golden-angle walk (no randomness, ever - layouts repeat).

Names draw beside every node - a diagram that will not say what its nodes are is furniture. Clicking selects and fires on_select with the id; dragging pins (warning ring); pin/release do it programmatically. The physics is assaulted headless: sixty relax steps keep every node inside the box, and a pinned node holds its ground to the decimal. The roadmap's note ran in reverse: this engine now stands ready to be the dev mesh's next chassis.

Source: src/sw_diagram.e · since Wave 4, Space & structure (2026-08-22). Live in the showroom: demo/sw_demo.e.

A living structure

create dia.make
n1 := dia.add_node (class="string">"simple_widgets")
n2 := dia.add_node (class="string">"simple_cairo")
dia.connect (n1, n2)
dia.set_on_select (agent on_node_picked)
page.put (dia.with_title (class="string">"the ecosystem"))

dia.pin (n1)          -- hold a node still
dia.relax_step        -- one physics tick (draw does this per frame)

Known limits

  • Straight edges only - curved/orthogonal routing is future.
  • No edge labels or weights yet; springs treat all edges alike.

Bugs & gotchas

  • Physics never fully sleeps - drag-pin nodes you need still.
  • add_node ids are positional (1..count); removing nodes is not supported yet, by design - rebuild instead.

Extension plans & possibilities

  • Edge labels and weights; node payloads (ANY) with reveal hooks; the dev mesh re-based on this engine; curved edge routing.
