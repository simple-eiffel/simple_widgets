Description

The board owns the truth (cards registry, lane assignment, move_card firing on_move); lanes are real widgets, each a pebble source (middle-click lifts the card under the pointer) and a drop hole (receiving asks the board to move here). A drop home is a quiet no-op. cards_in ordering, move semantics and the lane's card_at arithmetic are assaulted.

Source: src/sw_kanban.e · since Wave 5 (2026-08-22). Live in the showroom: demo/sw_demo.e.

A board

create kb.make
todo := kb.add_lane (class="string">"todo")
done := kb.add_lane (class="string">"done")
id := kb.add_card (todo, class="string">"ship wave 5")
kb.set_on_move (agent on_moved)
-- middle-click the card, drop on the done lane

Known limits

  • No in-lane reordering yet - cards stack in id order.
  • No card editing in place; compose with a form in a popover.

Bugs & gotchas

  • Card ids are stable forever; lanes change, ids never do.

Extension plans & possibilities

  • In-lane reordering; card colours by age; WIP limits with danger tint.
