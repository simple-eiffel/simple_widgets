Description

Records of (row key, column key, value) fold on demand; keys keep FIRST-APPEARANCE order - the data's own narrative. value_at, row_total, col_total and grand_total are public math, assaulted across all three modes.

Source: src/sw_pivot.e · since Wave 5 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Sales folded

create pv.make
pv.add_record (class="string">"north", class="string">"Q1", 120.0)
pv.add_record (class="string">"north", class="string">"Q1", 45.0)   -- folds into the same cell
pv.value_at (1, 1)                    -- 165.0

Known limits

  • One value dimension; no drill-down; no per-cell drill lists yet.

Bugs & gotchas

  • AVG of an empty cell answers 0, not error - a pivot hole is absence, not failure (the spreadsheet's law differs and says so).

Extension plans & possibilities

  • Drill-down on cell click; multiple aggregation columns.
