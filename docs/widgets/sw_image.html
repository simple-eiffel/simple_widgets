SW_IMAGE

A PNG, loaded once by cairo, contain-scaled and centered - honest placeholder when it is not.

Description

SW_IMAGE loads a PNG at creation (make_from_file) into a cairo surface and draws it scaled to fit its bounds with aspect preserved, centered (via SW_PAINTER.draw_image - the R2 monopoly holds). with_display_height requests a height; otherwise height derives from the laid-out width and the image's aspect. A file that fails to decode draws a crossed placeholder that says so - is_loaded reports the truth.

Source: src/sw_image.e · since Wave 2 (2026-08-22). Live in the showroom: demo/sw_demo.e.

The library showing its own logo

page.put ((create {SW_IMAGE}.make_from_file (class="string">"docs/images/logo.png"))
    .with_display_height (170.0))

-- defensive hosting
create img.make_from_file (user_supplied_path)
if not img.is_loaded then
    window.toast (class="string">"That file did not decode as a PNG", 3)
end

Known limits

  • PNG only (cairo's built-in decoder); JPEG et al. need a decoder service first.
  • Contain-fit only - no cover/stretch/tile modes yet.
  • The full-size surface stays in memory; very large images cost what they cost.

Bugs & gotchas

  • A bad path does not raise - cairo returns an error surface; the widget shows the placeholder and is_loaded is False. Check it when the path is user input.
  • Forward slashes are fine in paths on Windows; prefer them in source to dodge escaping layers.

Extension plans & possibilities

  • Cover and tile fit modes; sub-rect (sprite) display when the painter gains it.
  • Async/deferred load for galleries; a decoder service for JPEG.
  • Click-to-zoom lightbox composite (with the sheet layer).
