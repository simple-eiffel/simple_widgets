Description

Rows of (label, start day, duration) over SW_SCALE's x ladder; dependencies draw as elbows from a task's end into its successor's start, refused for unknowns and self-loops by contract; set_today plants the danger-red line. bar_x/bar_w/row_y are public scale math, assaulted (chained tasks abut exactly).

Source: src/sw_gantt.e · since Wave 5 (2026-08-22). Live in the showroom: demo/sw_demo.e.

A plan

create gt.make
t1 := gt.add_task (class="string">"design", 0, 4)
t2 := gt.add_task (class="string">"build", 4, 6)
gt.add_dependency (t1, t2)
gt.set_today (7)

Known limits

  • Days only (no hours); no critical-path math; bars are not draggable yet.

Bugs & gotchas

  • The horizon is computed from tasks - an empty gantt still draws a 0..1 ladder honestly.

Extension plans & possibilities

  • Drag to reschedule; progress fills; critical-path tinting.
