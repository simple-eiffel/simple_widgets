Description

SW_STATUS_BAR renders left and right text zones in mono on the variant surface with a hairline above - the desktop footer bar. It is presentational: set_left / set_right and it repaints next frame. The demo uses it as live telemetry (selection reports, toggle states, chosen files).

To attach it to the window's bottom edge, use the spacer idiom: root.put (create {SW_SPACER}.make); root.put (statusbar) - containership pins it at any window height.

Source: src/sw_status_bar.e · since Wave 2 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Live telemetry

create statusbar.make
statusbar.set_left (class="string">"ready")
statusbar.set_right (class="string">"38 widgets and counting")
root.put (create {SW_SPACER}.make)
root.put (statusbar)

on_row_selected (a_i: INTEGER)
    do
        statusbar.set_left ({STRING_32} class="string">"row " + a_i.out + {STRING_32} class="string">" selected")
    end

Known limits

  • Two zones only; no per-zone widgets (chips, progress) yet.
  • Text does not ellipsize; very long messages overlap in narrow windows.

Bugs & gotchas

  • Mid-flow placement floats the bar among content - almost never what you want; use the spacer idiom.

Extension plans & possibilities

  • N-zone layout hosting real widgets (progress, chips) - the app-shell footer.
  • Click zones with agents (e.g. click the count to open a panel).
