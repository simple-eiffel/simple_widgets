Description

SW_NUMBER_BOX holds an INTEGER value between min_value and max_value - the bounds are a class invariant, so an out-of-range value cannot exist. Up/down spinner zones and the mouse wheel step by step; on_change fires with the new value.

Source: src/sw_number_box.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

A bounded quantity

create nb.make (50, 0, 100, agent on_number_changed)
nb.set_step (5)
page.put (nb)

on_number_changed (a_v: INTEGER)
    do
        headline.set_text (class="string">"number box: " + a_v.out)
    end

Known limits

  • Integers only (REAL variant queued).
  • Direct typing SHIPPED 2026-08-23: digits build a buffer, Enter parses and clamps, Escape abandons.

Bugs & gotchas

  • set_value clamps rather than rejects - passing 999 into a 0..100 box yields 100, silently. The invariant holds either way.

Extension plans & possibilities

  • Editable value area (single-line text box fusion) with parse-on-commit.
  • REAL_64 variant with precision control; unit suffixes (px, %, pt).
  • Hold-to-repeat on the spinners.
