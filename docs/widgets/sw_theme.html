Description

SW_THEME is the single source of visual truth: surfaces (background, surface, surface_variant), ink (ink, ink_muted), semantics (accent, success, warning, danger), washes (soft tints of the semantics for fills), outline, corner radius, three type roles (UI, mono, body families) and the metric scale (size_body 16, size_label 13, size_chip 11, line_height 30, button_height 38, chip_height 24, pad 12 - sized for readability on real eyes).

Two palettes ship: make_light and make_dark. The class invariant enforces WCAG contrast on itself - ink against surface at 4.5:1, muted ink at 3:1 - so an unreadable theme cannot exist as an object.

Appearance model (S03): appearance = structure × style × theme. Widgets decide which token to use for a part in a state; the theme decides what that token is. Swap the whole look at runtime with window.set_theme - the next frame wears it.

Source: src/sw_theme.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

Dark by default, swapped live

create theme.make_dark
create window.make (class="string">"app", 100, 100, 900, 700, theme)

-- later, from a menu action:
create light.make_light
window.set_theme (light)   -- every widget re-renders in the new palette

Customising tokens

create t.make_dark
t.set_semantics (0x4F9CF9, 0x34C98E, 0xE7B93C, 0xE06C55)
t.set_washes (0x24344A, 0x1D3A2C, 0x3D330E, 0x40231C)
t.set_families (class="string">"Segoe UI", class="string">"Cascadia Mono", class="string">"Georgia")

Known limits

  • Metrics are fixed per theme instance - there is no global text-scale knob yet (planned; see Future).
  • Two built-in palettes; custom palettes are built by mutating a base via the setters.
  • Fonts resolve through cairo's toy API: no automatic glyph fallback across families.

Bugs & gotchas

  • The WCAG invariants are real contracts: hand a theme a low-contrast ink/surface pair under an assertion-checked build and it dies at the assignment, not at paint time.
  • Colours are NATURAL_32 RGB (no alpha in tokens); alpha lives in painter calls like set_color_alpha.

Extension plans & possibilities

  • A scale factor multiplying the whole metric set - Larry's grow/shrink-font control applied theme-wide, or per container.
  • Named palette registry (load/save themes).
  • High-contrast palette meeting WCAG AAA.
  • Per-widget style variants layered between kind and theme (S03's style axis, deepened).
