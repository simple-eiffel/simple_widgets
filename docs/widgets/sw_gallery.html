Description

As many columns as the width allows (columns_now), rows as needed, cell_at slot arithmetic assaulted including the beyond-the-last hole. Click selects, rings, and reports.

Known limits

  • Uniform thumb size; no lazy loading (all images decode at add).

Bugs & gotchas

  • preferred_height answers from rows_needed - width must be set (or arranged) before the answer means anything.

Extension plans & possibilities

  • Lazy decode; lightbox pairing with the carousel; drag-reorder.
