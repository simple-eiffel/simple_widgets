Description

SW_SEGMENTED is the one-of-N control worn as buttons: a track pill holding segments, the selected one filled accent, the hovered one raised. The first segment is chosen at birth (same law as the radio group - a choice control always holds a choice); clicking moves the selection and fires on_change (index); re-selecting the current segment is silent. Use it for view switches (List / Grid / Cards); use SW_RADIO_GROUP when the choice reads as a form field.

Source: src/sw_segmented.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

A view switch

create seg.make
seg := seg.with_segment (class="string">"List").with_segment (class="string">"Grid").with_segment (class="string">"Cards")
seg.set_on_change (agent on_view_changed)

on_view_changed (a_i: INTEGER)
    do
        statusbar.set_left ({STRING_32} class="string">"view: " + seg.selected_text)
    end

Known limits

  • Icon segments SHIPPED 2026-08-23: with_icon_segment (glyph); the shared seg_w measure keeps draw, click and layout in lockstep.
  • No per-segment disabling yet.
  • Fixed segment widths from label advance - no equalized widths option.

Bugs & gotchas

  • Click zones are measured with the same font the draw uses; if you restyle in a descendant, keep draw and handle_click measuring identically or zones will drift.

Extension plans & possibilities

  • Icon segments; equal-width mode; per-segment enabled flags.
  • A sliding selection animation on the heartbeat.
