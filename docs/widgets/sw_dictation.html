Description

A SERVICE in its own speechkit cluster - only targets that want the dependency add it (the devkit lesson applied to packaging; the library core stays lean). make (model_path) loads whisper through simple_speech when the file exists and stays HONESTLY UNREADY when it does not - the demo's mic button greys itself through set_enabled_when instead of crashing.

Two halves: start_listening / stop_and_deliver ride the microphone via simple_audio's recorder; transcribe_wav is the file-shaped half - and its assault is REAL: the suite loads ggml-base.en and turns an actual sample wav into actual words on every run (skipping honestly, still green, on machines without the model).

Runtime freight: whisper.dll and its ggml siblings must stand beside the exe - the cairo.dll standing rule, extended.

Source: src/sw_dictation.e · since Wave 6 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Known limits

  • Push-to-talk only - no VAD/streaming partials yet.
  • English base model in the demo; any ggml model path works.

Bugs & gotchas

  • The first transcription pays the model load (~a second); keep the service alive, not per-utterance.
  • ship whisper.dll + ggml*.dll beside the exe or is_ready lies... no - creation fails to load and is_ready is False, honestly.

Extension plans & possibilities

  • Streaming partial results into the box as you speak; VAD auto-stop; model picker.
