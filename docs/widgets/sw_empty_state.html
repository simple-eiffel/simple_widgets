Description

SW_EMPTY_STATE is what a blank region says instead of staying blank: a drawn open-tray glyph, a bold title, a muted message, and optionally one underlined action (set_action (label, agent)) that fires on click in the action zone. Use it in lists with no rows, searches with no hits, fresh documents with no content.

Source: src/sw_empty_state.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

page.put (empty)

Known limits

  • One action only; the message is a single non-wrapping line for now.
  • Pictogram choice SHIPPED 2026-08-23 via set_glyph_kind; unset, the tray stands.

Bugs & gotchas

  • The action zone is the band below the message - the glyph and title are deliberately inert so stray clicks do nothing.

Extension plans & possibilities

  • Wrapped multi-line messages (borrowing SW_LABEL's body wrap).
  • Glyph choices SHIPPED 2026-08-23: set_glyph_kind picks any drawn glyph (search, error, offline...); the tray remains the default.
  • Secondary action slot.
