Description

SW_ACCORDION stacks titled headers whose content shows only while open. The chevron tells the state (right shut, down open); clicking a header toggles. Exclusive by default - the classic accordion law, held by a postcondition: opening a section closes the others, so open_count is at most one. set_exclusive (False) allows independent sections. on_change (index) fires after any toggle; query is_section_open for the new truth.

Sections host any widget - the demo folds a whole SW_TIMELINE into one.

Source: src/sw_accordion.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Three sections, one open at a time

create accordion.make
accordion.add_section (class="string">"Details", details_column)
accordion.add_section (class="string">"Timeline", timeline)
accordion.add_section (class="string">"Danger zone", danger_column)
accordion.set_on_change (agent on_section_toggled)

on_section_toggled (a_i: INTEGER)
    do
        if accordion.is_section_open (a_i) then
            statusbar.set_left ({STRING_32} class="string">"opened: " + accordion.sections.i_th (a_i).title)
        end
    end

Known limits

  • No open/close animation - sections snap (heartbeat easing is a future).
  • Headers are text + chevron only; no per-section badges or icons yet.
  • No keyboard operation until focus traversal lands.

Bugs & gotchas

  • Toggling reflows everything below the accordion - inside a scrolling body that is fine; in a fixed layout give the region room or accept the jump.
  • Content is measured at accordion width minus the inset; very wide fixed-width children will clip.

Extension plans & possibilities

  • Height easing on the heartbeat (open unfolds instead of snapping).
  • Header accessories: badges, secondary text, per-section enabled flags.
  • Lazy section builders (agents, menu-style) for expensive content.
