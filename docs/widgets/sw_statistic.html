Description

SW_STATISTIC renders a dashboard figure: the value large and bold, the label muted beneath, and optionally a delta beside the value wearing its semantic - success green when is_delta_positive, danger red otherwise. Compose several in an SW_ROW for a stat strip.

Source: src/sw_statistic.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

A stat strip

create s.make (class="string">"assault tests", class="string">"35")
s.set_delta (class="string">"+10", True)
strip.put (s)
strip.put (create {SW_STATISTIC}.make (class="string">"native controls", class="string">"0"))

Known limits

  • Static text values - no number formatting/animation built in.
  • One delta; no sparkline pairing yet (charts are Wave 4).

Bugs & gotchas

  • The delta's sign glyph is yours to include in the text ('+7') - the widget colours, it does not spell.

Extension plans & possibilities

  • Count-up animation on the heartbeat when the value changes.
  • Sparkline pairing when the Wave 4 charts cluster lands.
  • Number formatting helpers (thousands separators, units).
