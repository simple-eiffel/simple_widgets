Description

SW_DROPZONE is the visible half of a window-wide capability: the pump now accepts shell drags (DragAcceptFiles) and answers WM_DROPFILES by buffering every dropped path (wide, newline-joined - the clipboard pull pattern, since the event queue carries only integers) and pushing event 18 with the drop point. The window parses the buffer (surrogate-paired, R8), splits the paths, and walks the spine from the widget under the point to the first whose accepts_files is true, handing it receive_files (paths, x, y) - the pebble protocol's file-shaped sibling, available to ANY widget that opts in.

The zone itself draws a tray-and-arrow glyph with an invitation line, brightens on hover, and fires on_drop (paths); last_paths keeps the most recent delivery. Proven both ways on day one: a forged HDROP through the full chain, and Larry's real drag from Explorer.

Source: src/sw_dropzone.e · since Wave 3 finale (2026-08-22). Live in the showroom: demo/sw_demo.e.

Receiving files

create dropzone.make (class="string">"Drop files here from Explorer")
dropzone.set_on_drop (agent on_files_dropped)
page.put (dropzone)

on_files_dropped (a_paths: ARRAYED_LIST [STRING_32])
    do
        statusbar.set_left ({STRING_32} class="string">"dropped " + a_paths.count.out
            + {STRING_32} class="string">" file(s): " + a_paths.first)
    end

-- ANY widget may opt in instead:
--   redefine accepts_files (True when willing) and receive_files.

Known limits

  • No drag-OVER tracking: WM_DROPFILES delivers only the final drop, so there is no highlight-while-dragging (that is OLE DnD - an S04 future). Hover highlight is mouse-based.
  • Paths only - no in-memory data formats (also OLE territory).
  • The pump's drop buffer holds 16K wide characters; a pathological thousand-file drop truncates (count arrives intact).

Bugs & gotchas

  • Drops route through active_root like clicks: a drop while a modal sheet is up lands in the sheet's tree, not the page beneath - consistent, and occasionally surprising.
  • receive_files requires accepts_files (a contract): redefine them TOGETHER.

Extension plans & possibilities

  • OLE DnD for drag-over feedback, drag-out (exporting), and data formats.
  • Extension filtering convenience on the zone (the file dialog's suffix rule).
  • Directory drops expanded to contents on request.
