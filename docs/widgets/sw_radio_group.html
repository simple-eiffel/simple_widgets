Description

SW_RADIO_GROUP lays its options in a row - ring, dot when selected, label - and guarantees exactly one choice: adding the first option selects it (an all-empty radio group is a small lie no real toolkit tells). Clicking an option moves the selection and fires the change agent.

The rings are drawn with the painter's circle_stroke / circle_fill - primitives born here: the group originally called cairo's arc raw, and cairo joins arcs to the current pen position with a straight line. Users saw dashes through every circle. The fix (path hygiene) now lives in SW_PAINTER where nobody can skip it.

Source: src/sw_radio_group.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

Options, fluent

buttons.put ((create {SW_RADIO_GROUP}.make)
    .with_option (class="string">"Alpha").with_option (class="string">"Beta").with_option (class="string">"Gamma"))
-- selected_index is already 1: the first option is chosen at birth

Known limits

  • Vertical orientation SHIPPED 2026-08-23 (set_vertical: drawn, clickable, measured), with per-option enablement.
  • No per-option disabling yet.

Bugs & gotchas

  • There is deliberately no 'nothing selected' state once options exist - design forms accordingly (add an explicit 'None' option if absence is a real choice).

Extension plans & possibilities

  • Vertical orientation flag.
  • Radio cards (rich content per option) as a component-layer composite.
