Description

The line chart's soul with no chrome at all - no axes, no insets, no labels. Values normalize to the widget's own box (fraction_of, public and assaulted: the floor is 0, the peak is 1, and a FLAT series answers its honest midline 0.5 instead of dividing by nothing). The area washes under the line and the endpoint carries the emphasis dot - the reader's eye lands on NOW.

set_capacity makes it a rolling feed, the same idiom as the line chart. The demo pairs one with SW_STATISTIC - exactly the pairing that widget's page promised - both fed by the same render-bell subscription as the gauge and the big chart: four instruments, one after_render_actions.subscribe.

Source: src/sw_sparkline.e · since Wave 4, Indicators (2026-08-22). Live in the showroom: demo/sw_demo.e.

Paired with a statistic

create spark.make
spark.set_capacity (60)
create stat.make (class="string">"last frame", class="string">"0")
pair.put (stat)
pair.put (spark)

-- one subscription drives both:
window.after_render_actions.subscribe (agent on_frame_cost)
-- on_frame_cost: stat.set_value (ms.out + " ms"); spark.add_value (ms)

Known limits

  • One series; overlaid comparison sparks are a future.
  • No hover - at word size, the pairing statistic is the readout.

Bugs & gotchas

  • Normalization is per-window - the shape shows RELATIVE motion; absolute scale lives in whatever the spark is paired with.
  • An empty spark draws a quiet baseline, one value draws a dot - both honest.

Extension plans & possibilities

  • Win/loss variant (bars above/below a reference); band highlights.
