Description

SW_LOCALE answers Larry's regional-controls notice as policy, not flags: one small value object carrying date field order (mdy / dmy / ymd) and separator, month and short day names, the week's first day (ISO numbering, 7 = Sunday for the US default), 12/24-hour clock, and the decimal mark. Three creators ship: make_us (the project default), make_iso, make_european; names localize via set_names.

Distribution is two-level: SW_THEME carries a locale (US unless set_locale swaps it) as the ambient culture every regional control reads; and every regional control accepts a per-control override - the demo shows one window holding a US date field beside an ISO one.

The formatting brain lives here: format_date / parsed_date (generous on separators - any of / . - parses; exact on output) and format_time / parsed_time (24-hour always readable; AM/PM handled including the 12 AM = hour-zero trap). Impossible dates - month 13, Feb 30, Feb 29 outside leap years - return Void; the assault suite pins all of it, leap arithmetic courtesy of simple_datetime.

Source: src/sw_locale.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Ambient culture plus a per-control override

-- the theme's culture is ambient (US by default)
theme.set_locale (create {SW_LOCALE}.make_european)

-- one control disagrees, and may:
create iso.make_iso
date_box := date_box.with_picker_locale (iso)

-- the brain, directly:
create us.make_us
print (us.format_date (2026, 12, 25))      -- 12/25/2026
if attached us.parsed_time (class="string">"2:05 PM") as t then
    print (t.hour)                          -- 14
end

Known limits

  • Names ship in English; localize via set_names (no CLDR data bundled - Windows carries ICU when depth is ever needed).
  • No collation yet: sorted grids compare code points, not locale rules (S04).
  • format_number SHIPPED 2026-08-23: thousands grouping with the carried decimal mark, negatives and zero-decimal forms included.

Bugs & gotchas

  • first_day_of_week is ISO-numbered (1 = Monday .. 7 = Sunday) to match simple_datetime's day_of_week - US Sunday-first is 7, not 0.
  • parsed_date is generous about separators by design: a US user with a European keyboard habit still lands; field ORDER is what the locale enforces.

Extension plans & possibilities

  • Locale-aware number formatting (thousands, the carried decimal mark) for SW_NUMBER_BOX and SW_STATISTIC.
  • Collation hooks for SW_DATA_GRID sorting.
  • Windows ICU bridge for full CLDR names when a consumer demands it.
  • Timezone tools (Larry, 2026-08-22): SW_WORLD_CLOCK on the heartbeat and a band-map SW_TIMEZONE_PICKER graduating to the Wave 4 map.
