Description

SW_CHECK_BOX draws a rounded box, an accent check mark when is_checked, and a label; clicking anywhere on box or label toggles and fires on_change. State is queryable (is_checked) and settable programmatically (set_checked - silent, no agent fire, per the ecosystem's commands-do-not-echo convention).

Source: src/sw_check_box.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

Arming a dangerous action

buttons.put (create {SW_CHECK_BOX}.make (class="string">"Danger armed", True, agent on_toggle_danger))

on_toggle_danger
    do
        danger_button.set_enabled (armed_box.is_checked)
    end

Known limits

  • Tri-state SHIPPED 2026-08-23: set_indeterminate draws the dash; any click resolves to checked. The tree cascade remains queued.
  • Label is plain text (single style).

Bugs & gotchas

  • set_checked does not fire on_change - programmatic state is silent by design; call your handler yourself if you want the side effects.

Extension plans & possibilities

  • Tri-state for hierarchical selection (with SW_TREE).
  • Check-box groups with select-all headers.
