Description

A splitter of SW_TREE (directories on demand via plain base DIRECTORY - the file dialog's honesty) and SW_LIST (files of the selected folder, virtualized, case-blind sorted), with a path label telling the truth. The engine surface (subdirs, refresh_listing, file_count/file_name, enter_directory) is public and assaulted against a real fixture on disk.

Source: src/sw_file_manager.e · since Wave 5 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Browsing

Known limits

  • No rename/delete/copy operations - browsing and opening only, v1.
  • No drive switching; root is the given root.

Bugs & gotchas

  • subdirs and the listing read the disk on demand - a vanished folder lists empty rather than erroring.

Extension plans & possibilities

  • File operations behind confirmations; breadcrumbs; the dropzone marriage (drop files INTO the listing).
