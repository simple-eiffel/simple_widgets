SW_LABEL

Text in three roles - UI, mono, body - with honest wrapping and muted/coloured variants.

Description

SW_LABEL renders one run of themed text. Creations pick the role: make (explicit role/size/bold), make_ui (13px UI face), make_mono (13px mono), make_body (16px reading face - and wrapping by default: body text refuses to clip). as_muted drops to ink_muted; set_color pins any token; with_wrap opts other roles into wrapping; set_text updates live.

Source: src/sw_label.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

Roles and modifiers

root.put (create {SW_LABEL}.make (class="string">"simple_widgets", {SW_PAINTER}.Role_ui, 20.0, True))
root.put ((create {SW_LABEL}.make_mono (class="string">"the toolkit above simple_cairo")).as_muted)
card.put (create {SW_LABEL}.make_body
    (class="string">"Body text wraps at the container's width, because clipped words are lies."))
status := create {SW_LABEL}.make_mono (class="string">"ready")
status.set_text (class="string">"busy...")   -- live update

Known limits

  • One style per label - no inline mixed bold/colour runs (compose labels in a row, or wait for rich text).
  • Wrapping is per-word greedy; no ellipsis mode yet for single-line overflow.

Bugs & gotchas

  • UI and mono labels do NOT wrap by default - a long one inside a narrow splitter pane clips. That exact clip was a live bug report; body labels wrap for that reason. Use make_body or with_wrap for prose.

Extension plans & possibilities

  • Ellipsis truncation modes (end/middle) with full text in the tooltip.
  • Rich runs (per-range role/colour) - shared machinery with the text box's future syntax-colouring hook.
  • Links (click agents on ranges).
