SW_POPOVER (window capability)

An anchored light panel hosting any widget tree - the menu's richer cousin.

Description

Popovers are a window capability rather than a class: window.show_popover (content, x, y, width) presents any widget tree in a bordered panel anchored at a point - typically the foot of the widget that asked - with no backdrop: the page stays bright, the panel floats. Outside clicks and Escape dismiss; the panel clamps inside the window; input routes into the hosted tree, so its widgets are fully live (the demo hosts a working SW_RATING).

Choose by weight: a menu for a list of verbs, a popover for widgets and explanation, a drawer for a work surface, a centered sheet for a must-answer form.

Source: src/sw_popover.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Anchored help with live widgets

on_open_popover
    local
        col: SW_COLUMN
    do
        create col.make
        col := col.with_gap (8.0)
        col.put (create {SW_LABEL}.make_ui (class="string">"An anchored panel hosting real widgets:"))
        col.put (create {SW_RATING}.make (2, 5, Void))
        window.show_popover (col, anchor_button.x, anchor_button.y + anchor_button.height, 260.0)
    end

Known limits

  • No pointer arrow toward the anchor yet - the panel is a plain rounded rect.
  • Placement is clamp-into-window only; no automatic flip above the anchor when space below runs out.
  • One overlay at a time (a popover displaces a drawer, and vice versa).

Bugs & gotchas

  • Anchor coordinates are yours to compute - the widget's own x/y + height is the convention; there is no anchored-to-widget tracking if the layout later moves.

Extension plans & possibilities

  • Anchor arrow and auto-flip placement.
  • Hover-popovers (rich tooltips) sharing the dwell machinery.
  • SW_INSPECTOR's reveal panel rides exactly this capability.
