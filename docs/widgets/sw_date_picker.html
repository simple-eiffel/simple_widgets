SW_DATE_PICKER

A date field with culture: locale-ordered typing, invalid tint, and a calendar popover via the widget handshake.

Description

SW_DATE_PICKER inherits the whole SW_TEXT_BOX engine (the combo pattern) and adds dates: every edit re-parses in the effective locale's field order - ill-formed or impossible input wears the invalid tint (danger wash + border), good input updates selected_year/month/day and fires on_date_change (y, m, d). set_date writes back formatted per locale.

The calendar glyph at the right edge opens an SW_CALENDAR in a popover - via the new pending-popover handshake on the widget spine (the pending-menu handshake's sibling: the widget declares, the window presents at its foot). Picking a day writes the formatted date into the box and fires the change agent; the popover dismisses on outside click or Escape. Locale is per-control settable (with_picker_locale); otherwise the theme's culture governs - adopted for parsing on first draw.

Source: src/sw_date_picker.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

US ambient, ISO beside it

create date_us.make_picker           -- theme culture: MM/DD/YYYY
date_us.set_on_date_change (agent on_date_changed)

create date_iso.make_picker
date_iso := date_iso.with_picker_locale (create {SW_LOCALE}.make_iso)
-- same window, same control, YYYY-MM-DD - culture is a setting

Known limits

  • Auto-close-on-pick SHIPPED 2026-08-23: the calendar raises a one-shot close request the window honours; embedded calendars are unaffected (opt-in flag).
  • Before the first draw, a picker WITHOUT an override parses as US even under a non-US theme - it adopts the theme's culture when first painted. Set the override when typing precedes showing.

Bugs & gotchas

  • The glyph zone is the right 30px; clicks there never place the caret.
  • Clearing the box clears the date and the tint - emptiness is valid nothing, not an error.

Extension plans & possibilities

  • Auto-close the popover on pick (overlay-engine hook).
  • Min/max constraints delegated to the hosted calendar. - SHIPPED 2026-08-23 (set_min_date / set_max_date hand through at popover build).
  • A range variant (two fields, one calendar) on SIMPLE_DATE_RANGE.
