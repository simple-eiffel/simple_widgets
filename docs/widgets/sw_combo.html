SW_COMBO

Description

SW_COMBO inherits SW_TEXT_BOX, so everything the flagship can do - caret, selection, clipboard, context menu, keyboard map - works in the combo for free. It adds an options list and a 30px chevron zone at the right edge: clicking the chevron opens a drawn SW_MENU of the options (via the pending-menu handshake); picking one calls choose_option, which replaces the text, parks the caret at the end and fires on_change.

Typing and picking are equals: users may pick an option and refine it, or ignore the options entirely. Spellcheck is off by construction (option values are rarely dictionary words).

Source: src/sw_combo.e · since Wave 2 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Options plus free typing

create combo.make_with_options
combo.add_option (class="string">"Cairo")
combo.add_option (class="string">"Vision2")
combo := combo.with_option (class="string">"WEL").with_option (class="string">"simple_widgets")
combo.set_on_change (agent on_combo_changed)

-- programmatic pick: text becomes the option, caret at the end
combo.choose_option (2)
check combo.text.same_string_general (class="string">"Vision2") end

Known limits

  • No filter-as-you-type: the chevron always offers the full option list.
  • Long text can run beneath the chevron glyph (the click zone still wins).
  • The dropdown menu does not scroll; very long option lists will clamp to the window.

Bugs & gotchas

  • The chevron zone is the right 30px - a click there never places the caret. Users aiming at the end of a long value should click just left of the chevron.
  • Being a text box, the combo's invariant pins is_single_line forever - pasted newlines flatten to spaces.

Extension plans & possibilities

  • Autocomplete: filter the menu by the typed prefix, Down-arrow to enter it.
  • Scrolling dropdown via SW_LIST for hundreds of options.
  • Recent-entries memory (an app-supplied history agent).
