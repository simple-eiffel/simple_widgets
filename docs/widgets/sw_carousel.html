Description

Paths become SW_IMAGE organs; the current one draws letter-boxed between chevrons, dots name the count and jump directly. The paging model (next/previous wrap, go_to clamps, dot_at slot math) is public and assaulted; a missing file draws as a quiet frame, honestly.

Source: src/sw_carousel.e · since Wave 6 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Paging

create car.make
car.add_image (class="string">"one.png")
car.add_image (class="string">"two.png")
car.next        -- wraps at the end
car.go_to (2)
