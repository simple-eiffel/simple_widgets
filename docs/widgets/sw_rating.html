Description

SW_RATING draws max_stars stars: filled warning-amber up to value, outlined beyond. Hovering previews the would-be rating in accent. Clicking the k-th star sets k; clicking the star matching the current value clears to 0 - both fire on_change (value). The invariant pins 0 ≤ value ≤ max_stars.

The stars themselves are the painter's star_fill/star_stroke primitives - ten computed vertices with the same path hygiene the circle primitives learned from the radio-dash bug.

Source: src/sw_rating.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Rate and clear

create rating.make (3, 5, agent on_rated)
rating.set_tooltip (class="string">"Click a star to rate; click the same star to clear")

on_rated (a_v: INTEGER)
    do
        statusbar.set_left ({STRING_32} class="string">"rated " + a_v.out + {STRING_32} class="string">" of 5")
    end

Known limits

  • Whole stars only - no half-star display or input.
  • Read-write only; a display-only mode is a one-flag addition awaiting a consumer.

Bugs & gotchas

  • star_at clamps rightward overshoot to max but returns 0 left of the field - the same truncation-toward-zero lesson SW_LIST's row_at taught, applied at birth.

Extension plans & possibilities

  • Half-star precision (display first, then input by half-zones).
  • Read-only mode with value caption ('4.2 (128)').
  • Custom glyph agent (hearts, thumbs) over the same zone engine.
