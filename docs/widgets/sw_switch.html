Description

SW_SWITCH is the modern toggle: a pill track whose knob sits left (off) or right (on), accent-filled when on. Semantically it is a check box whose effect applies immediately - use switches for live settings, check boxes for choices gathered then submitted.

Source: src/sw_switch.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

A live setting

buttons.put (create {SW_SWITCH}.make (class="string">"Live updates", True, agent on_live_toggled))

on_live_toggled
    do
        if live_switch.is_on then
            window.toast (class="string">"Live updates on", 2)
        else
            window.toast (class="string">"Live updates off", 3)
        end
    end

Known limits

  • No sliding animation yet - the knob teleports (animation hooks are a windowing future item).

Bugs & gotchas

  • set_on is silent (no agent fire) - same convention as the check box.

Extension plans & possibilities

  • Knob travel animation from the tick.
  • Optional on/off captions inside the track.
