Description

Combo-and-box rows over a declared field list, joined ALL (AND) or ANY (OR). query_text is pure public string math, assaulted: numbers ride bare, text quotes with doubled inner quotes (O''Brien), contains becomes LIKE with wildcards, valueless clauses are skipped. This builds the question; executing it belongs to whoever owns a store.

Source: src/sw_query_builder.e · since Wave 5 (2026-08-22). Live in the showroom: demo/sw_demo.e.

A question

create qb.make (<<class="string">"name", class="string">"age">>)
qb.add_clause
qb.set_clause (1, 1, 1, class="string">"O'Brien")
qb.query_text   -- name = 'O''Brien'

Known limits

  • Flat clause list - no nested groups (parentheses) yet.

Bugs & gotchas

  • The emission quotes for SQL convention but is NOT injection-proof armour - parameterize at the store when stakes are real.

Extension plans & possibilities

  • Nested groups; per-field operator sets; date pickers as value editors.
