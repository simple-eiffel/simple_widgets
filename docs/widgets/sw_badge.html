Description

SW_BADGE renders a small danger-red pill with a count, or a bare presence dot (make_dot). Counts beyond 99 display as 99+; the caption query is public precisely so that truth is testable - the assault suite pins 7 → '7', 99 → '99', 150 → '99+'.

Source: src/sw_badge.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Counts and dots

row.put (create {SW_BADGE}.make_count (3))
row.put (create {SW_BADGE}.make_count (150))   -- renders 99+
row.put (create {SW_BADGE}.make_dot)           -- bare presence
unread.set_count (unread.count + 1)

Known limits

  • Standalone widget for now - no attach-to-corner-of-another-widget overlay yet.
  • Danger red only; semantic kinds are a small addition awaiting a consumer.

Bugs & gotchas

  • set_count (0) renders a pill saying 0 - hide the badge (or use the dot) when zero means nothing to say.

Extension plans & possibilities

  • Overlay anchoring: badge attached to any widget's corner (composition-layer helper).
  • Semantic kind parameter (accent/success/warning) mirroring SW_CHIP.
  • Auto-hide-at-zero policy flag.
