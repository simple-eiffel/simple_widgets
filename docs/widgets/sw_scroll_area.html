Description

SW_SCROLL_AREA gives a single child unlimited height inside a fixed viewport: the child lays out at its full preferred height, the viewport clips, the wheel and a draggable thumb move scroll_y between 0 and max_scroll. Use it for arbitrary content; for thousands of uniform rows use SW_LIST, which never even lays out the invisible.

Source: src/sw_scroll_area.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

A tall column in a short viewport

create sa.make (150.0)          -- viewport height
create tall.make
across 1 |..| 24 as i loop
    tall.put (create {SW_LABEL}.make_mono (class="string">"row " + i.item.out))
end
sa.set_child (tall)
split := create {SW_SPLITTER}.make (sa, right_pane)

Known limits

  • Vertical only; no horizontal scrolling.
  • One child (wrap multiples in a column).
  • No keyboard paging (PgUp/PgDn) yet.

Bugs & gotchas

  • The child is laid out at FULL height every frame - fine for dozens of widgets, wrong for thousands of rows. That is exactly the line between this class and SW_LIST.

Extension plans & possibilities

  • Horizontal mode and two-axis mode.
  • Scroll-into-view requests bubbling from focused children.
  • Kinetic wheel smoothing.
