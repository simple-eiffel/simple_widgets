Description

v1 is SHIPPED. Arm the lens from the demo's Dev menu: hovering any widget outlines it with a chip naming its class and size; right-clicking opens the REVEAL - a popover built fresh per ask, showing the class and geometry headline, layout hints, state flags, the full parent chain (the app shell narrated), the creator's dev_note, and the REFLECTOR attribute dump: the widget's actual fields with live values - its label, its wired agents, its protocol slots. First photograph: a button confessing label, on_click PROCEDURE, tooltip and kind.

A constraint discovered in the building (now oracle law): finalization strips debug-clauses regardless of ECF keys - they are a workbench facility, and F_code -keep preserves ASSERTIONS, not debug bodies. The release-absence gate therefore rides a different vehicle: a cluster-swapped DEV_FLAGS constant plus dead-code removal (designed in S04); v1 ships the runtime gate (is_dev_mode, off by default, nothing fires without the toggle).

SW_INSPECTOR is the dev-mode lens over a running face. With dev mode on, right-clicking any widget opens a reveal overlay instead of (or stacked above) its normal context menu, showing: its class (free at runtime via Eiffel's generating_type), bounds, grow/min/max hints, state flags, and the theme tokens in force. The engine is Eiffel's own reflection - REFLECTOR / TYPE: field_count, field_name, field (i) - so any widget's attributes and live values enumerate generically, with zero per-class authoring. An opt-in dev_note on SW_WIDGET carries only what reflection cannot know: intent, provenance, wiring rationale.

The mesh view is SHIPPED as its own instrument - see the SW_DEV_STUDIO page: force physics on the heartbeat (EiffelStudio Diagram Tool family), depth-limited harvest with plus-badged frontier expansion, a crowned root, kind/state colour grammar, all-names toggle, node context menu, and pick-and-drop re-rooting (middle-click lifts any control as its own pebble; drop it on the mesh).

The gate, as built. The debug-clause plan died on a discovery (now oracle law): finalization strips debug bodies regardless of ECF keys. The shipped gate is the devkit ECF override cluster: it swaps DEV_FLAGS (False to True) and DEV_LENS (no-op to armed), and SW_INSPECTOR / SW_MESH / SW_DEV_STUDIO exist ONLY inside devkit - release-shaped targets never compile them. Binary-measured: the sw_7guis exe holds 0 occurrences of any devkit class name in ascii, utf-16 or utf-32. Run-time: the Dev menu's Dev Mode toggle arms hover chips, right-click reveals (each now ending in a 'Mesh this subtree' doorway), and dev-mode middle-click picking.

Browser-inspector mining (Larry, 2026-08-22): the DevTools notions translate almost one-to-one, and three go further here. Element-pick mode (crosshair hover outlines the widget + a chip naming class and bounds - the window already tracks hover); the box-model overlay becomes a LAYOUT overlay (bounds, container padding/gap, grow/min/max annotations); the DOM tree panel is literally SW_TREE [SW_WIDGET] with bidirectional highlight - shipped machinery; the styles pane becomes the S03 appearance model NARRATED (kind + state, which tokens won, why); live CSS editing becomes token tweaking against the running theme - a theme-design tool falling out of the inspector; the event-listeners pane becomes the agent-wiring pane. Beyond the browsers: a CONTRACTS pane showing the live invariants guarding the selected widget, direct object identity (references, not selectors), and the REFLECTOR attribute dump as a props pane for free.

An AI-assist narrator rides later: once structure, state and wiring enumerate, answering 'why does this button look like this?' (which token, which state, which contract) is a small step - and one no desktop toolkit has shipped.

Known limits

  • The reveal popover shows a capped 14 reflected fields (make_for); the studio pane shows them ALL (make_full) inside a scroll area.
  • Reflection reads attributes, not computed queries - derived state needs dev_note or explicit surfacing.

Bugs & gotchas

  • The lens reveal only fires when no overlay is up (a popover would replace the sheet or drawer you are working in); inside the studio, use node clicks and the node context menu instead.
  • A pinned docked studio keeps the page LIVE - clicks outside the drawer land on the app, not on a dismiss.

Extension plans & possibilities

  • Mutation flash (React-DevTools style): pulse a mesh node when a reflected field changes between heartbeats.
  • Event-stream pane (the network tab's cousin): clicks/keys/drops logged with their targets.
  • Computed-vs-authored layout pane: preferred sizes vs granted bounds, with deltas.
  • AI narrator once the reveal data model settles.
