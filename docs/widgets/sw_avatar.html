SW_AVATAR

Description

SW_AVATAR shows up to two initials - first letters of the first and last words of display_name, upper-cased ('Larry Rix' → LR, 'cher' → C, blank → ?) - on a filled disc. The wash colour is chosen by a stable hash of the name, so the same person always wears the same hue across sessions and screens. with_diameter scales the whole disc, initials included.

Source: src/sw_avatar.e · since Wave 3 (2026-08-22). Live in the showroom: demo/sw_demo.e.

A people row

row.put (create {SW_AVATAR}.make (class="string">"Larry Rix"))
row.put (create {SW_AVATAR}.make (class="string">"Claude"))
row.put ((create {SW_AVATAR}.make (class="string">"Grace Hopper")).with_diameter (48.0))

Known limits

  • Photo avatars SHIPPED 2026-08-23: with_image clips any CAIRO_SURFACE to the disc (new painter primitive push_circle_clip) - pixel-assaulted: the corner stays background, the centre carries the photo.
  • Hash picks among the four theme washes; large rosters will share hues.

Bugs & gotchas

  • The hue hash runs over the exact name string - 'Larry Rix' and 'larry rix' wear different colours. Normalize names upstream if identity matters.

Extension plans & possibilities

  • Photo avatars: circular-clipped via push_circle_clip. - SHIPPED 2026-08-23.
  • Presence dot overlay (with SW_BADGE anchoring).
  • Avatar stacks (overlapping groups with a +N tail).
