Description

SW_TOOLBAR is a strip of compact drawn buttons: add_tool for plain actions, add_toggle for latching state (accent-washed while on), add_gap for cluster separators. Hovering a tool surfaces its hint as the widget tooltip.

Toggle state is queried by label - is_tool_on ("Bold") - so handlers never do index bookkeeping. The toggle flips before its agent runs; the handler reads the new truth.

Source: src/sw_toolbar.e · since Wave 2 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Tools, toggles, and one handler for both

create toolbar.make
toolbar.add_tool (class="string">"New", class="string">"Start fresh", True, agent on_new)
toolbar.add_tool (class="string">"Save", class="string">"Save the session", True, agent on_save)
toolbar.add_gap
toolbar.add_toggle (class="string">"Bold", class="string">"Latches - the status bar reports it", False, agent on_flip)
toolbar.add_toggle (class="string">"Italic", class="string">"Latches", False, agent on_flip)
root.put (toolbar)

on_flip
    do
        statusbar.set_right ({STRING_32} class="string">"bold " + on_off (toolbar.is_tool_on (class="string">"Bold"))
            + {STRING_32} class="string">" / italic " + on_off (toolbar.is_tool_on (class="string">"Italic")))
    end

Known limits

  • Icon items SHIPPED 2026-08-23 - the toolbar met its destiny; text items remain for the wordy.
  • No overflow chevron for narrow windows.
  • By-label queries assume unique labels per bar.

Bugs & gotchas

  • is_tool_on of an unknown or plain (non-toggle) label is simply False - no error; typos read as 'off'. Name toggles carefully.

Extension plans & possibilities

  • Drawn icon glyphs - SHIPPED 2026-08-23: add_icon_item (glyph, hint, action); the label lives in the tooltip.
  • Overflow menu; vertical orientation for tool rails.
  • Radio-style exclusive toggle groups.
