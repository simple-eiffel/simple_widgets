Description

SW_TREE's lazy flatten, identity-stable selection and virtualization, with SW_GRID_COLUMN values rendered beside every node. A header band names the columns; rows band per SW_SHEET's discipline. The slot math (column_x) and the header's row-offset arithmetic (row_at shifts under Header_h) are public and assaulted.

Source: src/sw_tree_table.e · since Wave 5 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Columns on a tree

Known limits

  • No header-click sorting - reordering a TREE reorders siblings, a semantic step deferred deliberately.

Bugs & gotchas

  • Column cells render from the same node object the tree row shows - keep value agents cheap; they run per visible row per frame.

Extension plans & possibilities

  • Sibling sorting; column resize grips; cell editors.
