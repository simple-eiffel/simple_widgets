Description

SW_ROW arranges children left to right with a gap. Each child gets its clamped preferred width; leftover space is distributed to children with a grow weight (the flex model), still respecting min/max anchors. This is the toolkit's unification of Vision2's containership with modern flex - one engine, both idioms.

put appends; add is its fluent twin returning the row; with_gap configures fluently at build time.

Source: src/sw_row.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

A verb row where one member stretches

create buttons.make
buttons.put (create {SW_BUTTON}.make_primary (class="string">"Open", agent do_open))
buttons.put (create {SW_BUTTON}.make (class="string">"Cancel", agent do_cancel))
buttons.put ((create {SW_TEXT_BOX}.make_single_line (class="string">"")).growing)
-- the text box absorbs all leftover width; buttons keep their size

Known limits

  • Wrapping SHIPPED 2026-08-23: with_wrapping reflows children into greedy lines (the pure wrap_starts math is assaulted with bare numbers); cross_axis places within a line (center default, top, stretch).
  • Vertical alignment is top-aligned per child height; no baseline alignment.

Bugs & gotchas

  • A row inside a column receives the column's full width; without any growing child the leftover is simply empty space at the right - by design, not a bug.

Extension plans & possibilities

  • Wrapping mode (flex-wrap). - SHIPPED 2026-08-23; grow shares are ignored while wrapping, flexbox's own law.
  • Cross-axis alignment - center/top/stretch SHIPPED 2026-08-23; BASELINE stays open (it needs per-face font metrics the toy text API does not expose).
