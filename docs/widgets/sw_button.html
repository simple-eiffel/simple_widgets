Description

SW_BUTTON draws a rounded button in one of four kinds - Kind_normal, Kind_primary (accent fill), Kind_quiet (borderless), Kind_danger - each mapping (kind, state) to theme tokens for fill, border and label. Hover, pressed and disabled states are painted distinctly; the action agent fires on click release inside.

Style queries (fill_color, border_color, label_color) and part painters (draw_background, draw_border, draw_label) are separated so descendants can restyle without re-owning geometry - the S03 appearance model in miniature.

Source: src/sw_button.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

The demo's button row

buttons.put ((create {SW_BUTTON}.make_primary (class="string">"Click Me", agent on_click_me))
    .with_tooltip (class="string">"Adds 10% to the progress bar"))
buttons.put (create {SW_BUTTON}.make (class="string">"Log Only", agent on_log_only))
buttons.put ((create {SW_BUTTON}.make (class="string">"Disabled", Void)).disabled)
buttons.put ((create {SW_BUTTON}.make (class="string">"Delete...", agent on_delete))
    .as_kind ({SW_BUTTON}.Kind_danger))
buttons.put (((create {SW_BUTTON}.make (class="string">"I grow", Void)).disabled).growing)

Known limits

  • Icon faces SHIPPED 2026-08-23: with_glyph beside the label, or alone when the label is empty (compact icon button).
  • No default-button / Enter-to-activate wiring (needs focus traversal first).
  • No repeat-fire on hold (spinners implement their own).

Bugs & gotchas

  • The kind attribute is named kind because variant is an Eiffel keyword (loop variants). The compiler taught us.
  • An agent created inside a creation procedure requires every attached attribute already set (VEVI); when a button's agent must reference the button itself, create it with Void and call set_on_click after.

Extension plans & possibilities

  • Icon + text faces from the drawn-glyph library - SHIPPED 2026-08-23 (25 kinds on SW_PAINTER, each pixel-proven).
  • Split buttons (action + chevron menu) and toggle buttons.
  • Keyboard activation once focus traversal lands.
