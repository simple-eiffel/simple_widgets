Description

SW_MENU is the toolkit's own popup: items carry (label, hint, enabled, action), separators score groups, disabled items render muted and refuse clicks. The window presents it (show_popup) above everything, clamped inside the window; hover highlights rows; a click runs the item's agent after closing; Escape or any outside button-down dismisses.

Menus are built fresh on every open - context menus, the menu bar and SW_SELECT all construct a new SW_MENU per presentation, so enablement always reflects live state. Stale menus cannot exist because kept menus do not exist.

History note: the native TrackPopupMenu was tried and abandoned (invisible-menu foreground quirks) - the drawn menu is both the R7-pure answer and the one that actually worked.

Source: src/sw_menu.e · since Wave 1 (2026-08-21). Live in the showroom: demo/sw_demo.e.

Building and offering (the pending-menu handshake)

handle_click (a_px, a_py: REAL_64): BOOLEAN
    local
        m: SW_MENU
    do
        create m.make
        m.add_item (class="string">"New Session", class="string">"Ctrl+N", True, agent on_new)
        m.add_item (class="string">"Save", class="string">"Ctrl+S", is_dirty, agent on_save)
        m.add_separator
        m.add_item (class="string">"Quit (decorative)", class="string">"", False, Void)
        pending_menu := m      -- the window takes it and presents
        Result := True
    end

Known limits

  • No submenus yet (flyout nesting is queued).
  • Hints are display-only - the shortcut text does not register accelerators.
  • No icons or check marks on items yet.

Bugs & gotchas

  • While a popup is open it owns the pointer; the frame echo still flushes (the heartbeat is global), so snapshots CAN photograph open menus - a hard-won property; do not reintroduce tick handling into popup phases.
  • Item agents run AFTER the menu closes - a handler that opens another menu or sheet is safe and common.

Extension plans & possibilities

  • Submenus with hover-open; item icons from the drawn-glyph set; check/radio items.
  • Real accelerator registration once a keymap service exists.
  • Type-ahead selection while open.
