Description

SW_SHEET renders a spreadsheet-shaped grid - rows 0-99, columns A-Z, headers frozen while the body scrolls on both axes (wheel; Shift+wheel sideways) - with click selection, arrow-key navigation that scrolls the selection into view, and an in-place cell editor opened by double-click or Enter (Enter commits, Escape cancels, Backspace edits).

The deliberate boundary: the sheet owns display and editing only. Values, formulas and change propagation belong to the host through two agents - on_cell_commit (row, col, text) fires when an edit lands (the host parses, evaluates, propagates, and pushes results back via set_cell_display), and formula_provider supplies what editing should start from (the raw formula, not the display). 7GUIs' Cells runs on exactly this split, with CELLS_ENGINE (demo7guis) as the reference formula engine: numbers, A0-Z99 references, arithmetic, parentheses, structural cycle detection poisoning cycles to #ERR.

The roadmap (per Larry's spreadsheet doctrine): SW_SHEET is tier one of three - the view; SW_DATA_GRID (Wave 3's crown) brings first-class columns; SW_SPREADSHEET (Wave 5) composes this sheet with a library-grade formula engine, ranges, a formula bar, TSV clipboard blocks and CSV in/out.

Source: src/sw_sheet.e · since Wave 3 / 7GUIs (2026-08-22). Live in the showroom: demo/sw_demo.e.

Wiring a formula host

create sheet.make (430.0)
sheet.set_on_cell_commit (agent on_cell_commit)
sheet.set_formula_provider (agent seed_formula)

on_cell_commit (a_row, a_col: INTEGER; a_text: STRING_32)
    do
        cells.commit (cells.key (a_row, a_col), a_text)
        across cells.touched as k loop
            sheet.set_cell_display (k // cells.Cols, k \\ cells.Cols, cells.display (k))
        end
    end

Known limits

  • Fixed geometry: 100x26, uniform 72x24 cells (variable sizes are SW_DATA_GRID's job).
  • Single-cell selection; no ranges, no block clipboard yet (Wave 5 composite).
  • The in-place editor is minimal (append/backspace/commit/cancel) - not the full SW_TEXT_BOX engine.
  • No scrollbars drawn yet - wheel and keyboard only (bars come with the grid work).

Bugs & gotchas

  • A synthetic double-click without a preceding single click never focuses the sheet - real users always click first; test benches must too.
  • The editor shows the FORMULA (via formula_provider) while the cell shows the VALUE - wire both agents or editing starts from emptiness.

Extension plans & possibilities

  • Row/column resize and scrollbars; range selection with block TSV copy/paste.
  • Promotion path: CELLS_ENGINE graduates library-grade for SW_SPREADSHEET (Wave 5) - ranges, SUM/AVG/MIN/MAX/COUNT, formula bar, CSV.
  • Cell renderers (semantic colouring, right-aligned numerics).
