Description

SW_FILE_DIALOG is a pure SW_COLUMN composition - title, mono path label, an SW_LIST of entries (directories first, both halves case-insensitively sorted, '..' always on top, accent ink + trailing slash on folders), a single-line name box, and Open/Save + Cancel verbs. Present it through the window's sheet layer; nothing native appears anywhere (R7).

Behaviour: single-click a file to put its name in the box; double-click (or open_entry) descends into folders and accepts files; '..' climbs. set_extension_filter (".png") hides non-matching files (folders always survive). on_accept receives the full joined path; on_cancel and Escape leave quietly. Directory access is plain base PATH/DIRECTORY - the toolkit gains no dependency.

A public inspection API (entry_count, entry_name, is_entry_directory, open_entry) exists because the assault suite demanded it - and any app scripting a picker will want it too.

Source: src/sw_file_dialog.e · since Wave 2 (2026-08-22). Live in the showroom: demo/sw_demo.e.

Open... from a menu

on_open_file
    local
        fd: SW_FILE_DIALOG
    do
        create fd.make_open (class="string">"D:/prod/simple_widgets")
        fd.set_extension_filter (class="string">".e")
        fd.set_on_accept (agent on_file_chosen)
        fd.set_on_cancel (agent on_file_cancelled)
        window.show_sheet (fd, 560.0)
    end

on_file_chosen (a_path: STRING_32)
    do
        window.close_sheet
        window.toast ({STRING_32} class="string">"Chosen: " + a_path, 2)
    end

Save mode

create fd.make_save (class="string">"D:/prod/output", class="string">"untitled.txt")
fd.set_on_accept (agent on_save_target)
window.show_sheet (fd, 560.0)

Known limits

  • No drive/root picker yet - it browses from the start directory; '..' stops at the drive root.
  • One extension filter at a time (no '*.png;*.jpg' sets yet).
  • No overwrite confirmation in save mode (the host app owns that policy for now).
  • No keyboard navigation of the entry list yet (arrives with SW_LIST's).

Bugs & gotchas

  • on_accept fires but does NOT close the sheet - the host closes (window.close_sheet) after taking the path. That asymmetry is deliberate: the host may validate and refuse.
  • Paths normalize to the OS separator; compare with PATH semantics, not string equality against your forward-slash input.
  • The dialog reads the directory at construction and on navigation - external changes are not watched; reopen to refresh.

Extension plans & possibilities

  • Drive/known-folder rail (Desktop, Documents, drives) on the left of the sheet.
  • Multi-pattern filters with a filter dropdown; hidden-file toggle.
  • New-folder button in save mode; overwrite confirm option.
  • Type-to-filter riding SW_COMBO's future autocomplete.
